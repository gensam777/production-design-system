# platforms/android

Gradle build for the Kotlin / Android side of the design system (ADR
[0013](../../governance/decisions/0013-cross-platform-architecture.md),
[0017](../../governance/decisions/0017-workspace-structure.md)).

| Module     | Package           | Path       | Status                                                                                                                                                           |
| ---------- | ----------------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `:tokens`  | `com.pds.tokens`  | `tokens/`  | **Generated** Kotlin (`src/main/kotlin/com/pds/tokens/`) by `npm run tokens:build` — do not edit. Plain Kotlin/JVM library.                                      |
| `:compose` | `com.pds.compose` | `compose/` | Jetpack Compose components (`DsButton`, alpha) — see [`compose/README.md`](compose/README.md). Icon sources in `icons/` are generated by `npm run icons:kotlin`. |

Build: `./gradlew build` from `platforms/android` (Gradle wrapper committed; JDK 21+ — the Robolectric
tests need it, bytecode targets 17 — Android SDK with platform 36 — Android Studio provides both). Versions live in
`gradle/libs.versions.toml` (ADR 0018). `npm run tokens:test` fails if the committed Kotlin
differs from what the token build generates, and `npm run icons:test` if `compose/…/icons/`
differs from the icon generator. Open `platforms/android` (not the repo root) in Android Studio.
