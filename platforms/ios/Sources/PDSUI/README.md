# PDSUI

SwiftUI components implementing the shared contracts in
[`design/contracts/`](../../../../design/contracts/) (Phase 5, ADR
[0018](../../../../governance/decisions/0018-cross-platform-button.md)). iOS 17+; macOS 14 is
the build / test host only. Components read the generated `PDSTokens` themes — never web CSS
or React APIs.

| Status | Component                                                                             |
| ------ | ------------------------------------------------------------------------------------- |
| alpha  | `DSButton` — [contract](../../../../design/contracts/components/button.contract.yaml) |

## Usage

```swift
import PDSUI

struct CheckoutView: View {
    @State private var isPlacingOrder = false

    var body: some View {
        DSButton("Place order", leadingIcon: .check, isLoading: isPlacingOrder) {
            isPlacingOrder = true
        }
        .disabled(cart.isEmpty)
        .dsTheme(.brandB)          // usually set once near the root
    }
}
```

### Theme

- `.dsTheme(_:)` sets the brand (`DSTheme.brandA` / `.brandB`) for a subtree; nests. Without
  it views use the default brand (Brand A). `@Environment(\.dsTheme)` reads it.
- `Color(_ value: DSColorValue)` and `.dsTextStyle(theme.typography.…)` for app UI. Text
  styles scale with Dynamic Type on the role's anchor (ADR 0016).
- **Fonts are not bundled.** Register the brand faces in the app under the PostScript names in
  `theme.fonts.sans.faces` (e.g. `Inter-Medium`, `Figtree-Medium`); PDSUI detects them at
  runtime. Unregistered → the system font at the same size and weight.

### DSButton

`DSButton(_ title, variant:, size:, leadingIcon:, trailingIcon:, isLoading:, action:)` — title
is a `LocalizedStringKey` (or a verbatim string), `variant` `.primary | .secondary | .tertiary
| .danger` (default `.primary`), `size` `.sm | .md | .lg` (default `.md`), icons are
`DSIconName` (the shared catalog).

| Contract          | SwiftUI                                                                                                                                                                             |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `disabled`        | `.disabled(_:)` — SwiftUI's own; also inherited from an ancestor. VoiceOver: "dimmed".                                                                                              |
| `loading`         | `isLoading:` — spinner only, size unchanged, variant colors, action blocked, stays enabled and focusable; VoiceOver value "Loading" (no busy trait on iOS). Ignored while disabled. |
| `events.activate` | `action` — touch, keyboard, Switch Control, Voice Control, VoiceOver                                                                                                                |
| text scaling      | Dynamic Type on the label role's anchor; label wraps; 32 / 40 / 48 are minimum heights; icons + spinner scale on the same anchor                                                    |
| hit target        | ≥ 44 × 44pt, extended outside the layout from the measured size                                                                                                                     |
| focus             | system focus effect (Full Keyboard Access)                                                                                                                                          |
| hover             | pointer only (iPad trackpad / mouse)                                                                                                                                                |
| reduced motion    | spinner stops turning; state color transition skipped                                                                                                                               |

Accessibility hints and other platform accessibility modifiers apply to `DSButton` as to any
view (`.accessibilityHint(_:)`).

## Structure

```
Button/      DSButton (public view + internal ButtonStyle) · DSButtonTokens (contract paths → PDSTokens key paths) · DSButtonAppearance (pure state / token resolution)
Spinner/     DSSpinner — internal; 2pt 270° ring on motion.spinner
Icons/       DSIconName + LucidePaths — GENERATED by `npm run icons:swift` (do not edit) · DSIconView (internal)
Theme/       .dsTheme environment · Color(DSColorValue) · .dsTextStyle
Previews/    #Preview gallery (DEBUG only)
Resources/   localized strings ("Loading")
```

## Review in Xcode

1. `npm run tokens:build` is **not** needed — `PDSTokens` sources are committed.
2. Open the package: `open Package.swift` (or File ▸ Open… the repo root in Xcode).
3. Choose the **PDSUI** scheme and an iOS Simulator destination (e.g. iPhone 17 Pro).
4. Open `Previews/DSButtonPreviews.swift` and show the canvas (Editor ▸ Canvas, ⌥⌘↩).
5. Previews: **Brand A**, **Brand B**, **Dynamic Type · xxxLarge**, **Dynamic Type · AX3**,
   **Dynamic Type · xSmall**. Use the canvas's live mode to press buttons and try the two
   "Submit" pending-action demos; Canvas Device Settings toggle Reduce Motion / Dynamic Type.

## Checks

```
swift test                                                         # Swift Testing, macOS host
xcodebuild -scheme PDSUI -destination 'generic/platform=iOS Simulator' build
npm run icons:test                                                 # generated icon sources are current
npm run contracts:validate                                         # ios-reference: enums, defaults, token set
```

The tests compare `DSButtonTokens` with the contract's `tokens` section cell by cell (read
from the YAML), check every key path names the generated member its contract path names, and
resolve every binding in Brand A and Brand B.
