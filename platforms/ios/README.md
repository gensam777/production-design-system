# platforms/ios

Swift sources for the Swift package declared in the repo-root [`Package.swift`](../../Package.swift)
(ADR [0013](../../governance/decisions/0013-cross-platform-architecture.md),
[0017](../../governance/decisions/0017-workspace-structure.md)).

| Module      | Path                 | Status                                                                                                                                                              |
| ----------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PDSTokens` | `Sources/PDSTokens/` | **Generated** by `npm run tokens:build` — do not edit. Committed so SwiftPM needs no Node.                                                                          |
| `PDSUI`     | `Sources/PDSUI/`     | SwiftUI components (`DSButton`, alpha) — see [`Sources/PDSUI/README.md`](Sources/PDSUI/README.md). Icon sources in `Icons/` are generated by `npm run icons:swift`. |

`npm run tokens:test` fails if `Sources/PDSTokens/` differs from what the build generates, and
`npm run icons:test` if `Sources/PDSUI/Icons/` differs from the icon generator. Tests:
`Tests/PDSUITests/` (Swift Testing, `swift test`). CI builds `PDSTokens` in a Swift 6 Linux
container (`swift build --target PDSTokens`) and runs `swift test` plus an iOS Simulator build
of `PDSUI` on macOS.
